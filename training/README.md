# آموزش و ارزیابی مدل

## داده و ورودی‌ها

اسکریپت فایل Excel را از شیت `گزارش روزانه` می‌خواند.

چهار ویژگی مدل دقیقاً با این ترتیب استفاده می‌شوند:
1. وضعیت سیر قبل (۱=سالم، ۰=خراب)
2. روز از آخرین خرابی در سیر
3. زمان تعمیرات امروز (ساعت)
4. هزینه تعمیر (یورو)

هدف: قابلیت سیر امروز.

تاریخ و شماره لکوموتیو از ویژگی‌های مدل حذف شده‌اند؛ تاریخ فقط در نرم‌افزار برای مرتب‌سازی رکوردهای ورودی کاربرد دارد و شماره لکوموتیو شناسه است.

## روش ارزیابی و آموزش

1. داده‌های معتبر به‌صورت تصادفی و با seed ثابت به ۸۰٪ آموزش و ۲۰٪ آزمون تقسیم می‌شوند.
2. RandomForestRegressor فقط با ۸۰٪ آموزش داده می‌شود.
3. روی ۲۰٪ کنارگذاشته‌شده MAE، RMSE و R² محاسبه می‌شوند.
4. یک DummyRegressor مبتنی بر میانگین نیز روی همان بخش آزمون سنجیده می‌شود.
5. پس از ثبت معیارهای ارزیابی، مدل نهایی با تمام ردیف‌های معتبر آموزش داده می‌شود و به ONNX تبدیل می‌شود.

برای کنترل اندازه مدل و زمان بارگذاری روی CPUهای قدیمی، جنگل فعلی عمداً محدود شده است: ۸۰ درخت، حداکثر عمق ۱۴، حداقل ۸ نمونه در هر برگ و حداکثر ۱۲۸ برگ برای هر درخت. این محدودیت ممکن است بر معیارهای پیش‌بینی اثر بگذارد؛ معیارها را با گزارش خروجی مقایسه کن و کیفیت را فدای کوچک شدن مدل نکن.

**نکته ارزیابی:** تقسیم تصادفی برای مقایسه فنی اولیه استفاده شده و آزمون مستقل زمانی/لکوموتیوی نیست؛ ممکن است تخمین خوش‌بینانه‌ای بدهد.

## خروجی‌ها

- `public/models/locomotive_model.onnx`: مدل نهایی
- `public/models/metadata.json`: مشخصات مدل و معیارهای ارزیابی
- `backend/models/model_bundle.zip`: بسته آماده نصب در برنامه
- `training/output/evaluation_report.json`: گزارش ارزیابی و baseline
- `training/output/evaluation_predictions.csv`: مقادیر واقعی، پیش‌بینی و خطا
- `logs/training.log`: گزارش آموزش

## اجرای آموزش در Windows

1. فایل `LocomotivDataSet.xlsx` را در `training/data/` قرار بده.
2. یک محیط مجازی بساز و وابستگی‌های `requirements-train.txt` را نصب کن.
3. اجرا کن:

```powershell
python training/train_model.py
```

پس از پایان موفق آموزش، فایل `backend/models/model_bundle.zip` برای نصب مستقیم در برنامه آماده است.

## سخت‌افزار

GPU لازم نیست؛ آموزش روی CPU انجام می‌شود. زمان آموزش به پردازنده و نسخه کتابخانه‌ها وابسته است. محدودیت‌های مدل با هدف مناسب‌تر شدن اجرای ONNX روی سیستم‌های معمولی انتخاب شده‌اند.

## محدودیت اعتبار

مستندات فایل Excel فعلی داده‌ها را مصنوعی/تصادفی معرفی می‌کند. بنابراین حتی اگر MAE و RMSE ظاهراً مناسب یا R² بالا باشند، این معیارها اعتبار پیش‌بینی خرابی واقعی لکوموتیو را ثابت نمی‌کنند.
