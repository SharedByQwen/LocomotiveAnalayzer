# Backend API

این سرویس مدل ONNX را روی سرور/رایانه میزبان بارگذاری می‌کند و پیش‌بینی را از طریق HTTP API انجام می‌دهد. مرورگر هیچ فایل ONNX را دانلود یا اجرا نمی‌کند.

## محل قرار دادن مدل

فایل ZIP خروجی Google Colab را بدون Extract کردن در این مسیر قرار بده:

`backend/models/model_bundle.zip`

ZIP باید شامل این دو فایل باشد (در هر پوشه‌ای داخل ZIP باشند قابل شناسایی‌اند):
- `locomotive_model.onnx`
- `metadata.json`

با شروع Backend، فایل ZIP خوانده می‌شود و مدل در حافظه بارگذاری می‌شود. خود ZIP نیز در همان مسیر نگه‌داری می‌شود. نیازی به Extract دستی نیست. می‌توانی ZIP جدید را از رابط برنامه هم آپلود کنی؛ مدل جدید ابتدا اعتبارسنجی می‌شود و فقط در صورت موفقیت جایگزین مدل قبلی خواهد شد.

## اجرای Windows

1. یک بار `scripts/setup_backend_windows.bat` را اجرا کن.
2. `scripts/run_app_windows.bat` را اجرا کن.
3. برنامه در `http://127.0.0.1:5173` باز می‌شود.

Backend روی `127.0.0.1:8000` اجرا می‌شود و Vite درخواست‌های `/api` را به آن Proxy می‌کند.

## API

- `GET /api/health`
- `GET /api/model/status`
- `POST /api/model/upload` با multipart field به نام `file` و فایل ZIP
- `POST /api/predict` با JSON مثل `{"records":[[1,7,5,10]]}`

## استقرار روی سرور

Backend را به‌عنوان سرویس دائمی با Uvicorn یا process manager اجرا کن؛ فایل ZIP و پوشه `backend/models` باید روی دیسک پایدار سرور باشند. Reverse proxy وب‌سرور باید مسیر `/api` را به Uvicorn هدایت کند و فایل‌های build فرانت‌اند را جداگانه سرو کند.

**امنیت:** این نسخه برای اجرای محلی و شبکه توسعه است. پیش از قراردادن API در اینترنت عمومی، احراز هویت، محدودیت دسترسی آپلود، TLS و محدودیت نرخ درخواست اضافه کن. فعلاً سرویس فقط روی loopback اجرا می‌شود.
