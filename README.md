# LocomotiveAnalayzer

نسخه محلی ابزار تحلیل قابلیت سیر لکوموتیو برای Windows.

## قابلیت‌ها
- رابط React و TypeScript با اجرای محلی Vite
- ورود دستی چند رکورد مستقل
- مرتب‌سازی رکوردها بر اساس تاریخ صعودی
- ورودی مدل فقط چهار ویژگی: وضعیت سیر قبل، روز از آخرین خرابی، زمان تعمیرات امروز و هزینه تعمیر
- تاریخ فقط برای مرتب‌سازی و شماره لکوموتیو فقط شناسه است.
- اجرای مدل ONNX داخل مرورگر با ONNX Runtime Web
- محاسبه امتیاز نهایی با میانگین وزن‌دار خطی؛ جدیدترین رکورد وزن بیشتری دارد.
- لاگ ساختاریافته در کنسول و خروجی JSON برای عیب‌یابی

هشدار: راهنمای دیتاست فعلی، داده‌ها را مصنوعی و تصادفی معرفی می‌کند. معیارهای مدل فعلاً اعتبار عملیاتی ندارند.

## اجرای رابط
پیش‌نیاز: Node.js LTS

1. فایل scripts/setup_windows.bat را اجرا کن.
2. در پوشه پروژه دستور npm run dev را اجرا کن.
3. آدرس http://127.0.0.1:5173 را باز کن.

## آموزش مدل
1. فایل LocomotivDataSet.xlsx را در مسیر training/data/ قرار بده.
2. scripts/setup_training_windows.bat را اجرا کن.
3. scripts/train_model_windows.bat را اجرا کن.
4. دو فایل locomotive_model.onnx و metadata.json در public/models ساخته می‌شوند.
5. صفحه برنامه را refresh و مدل را بارگذاری کن.

گزارش آموزش در logs/training.log قرار می‌گیرد.

## ارسال لاگ برای دیباگ
- از پایین برنامه دکمه خروجی لاگ تشخیصی JSON را بزن و فایل را همین‌جا بفرست.
- خطاهای فنی در کنسول مرورگر با پیشوند [LocomotiveAnalyzer] ثبت می‌شوند.
- اگر خطا در آموزش رخ داد، logs/training.log را بفرست.
- لاگ‌ها مقادیر عددی ورودی را ذخیره نمی‌کنند؛ فقط تعداد رکورد، تاریخ‌ها، شناسه‌ها و خلاصه خروجی ثبت می‌شود.
