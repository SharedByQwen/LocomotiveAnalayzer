# LocomotiveAnalayzer

نسخه محلی ابزار تحلیل قابلیت سیر لکوموتیو برای Windows.

## قابلیت‌ها
- رابط React و TypeScript با اجرای محلی Vite
- ورود چند رکورد مستقل؛ دیتاست آموزشی وارد نرم‌افزار نمی‌شود.
- مرتب‌سازی رکوردهای واردشده بر اساس تاریخ صعودی
- ورودی مدل فقط چهار ویژگی: وضعیت سیر قبل، روز از آخرین خرابی، زمان تعمیرات امروز و هزینه تعمیر
- تاریخ فقط برای مرتب‌سازی و شماره لکوموتیو فقط شناسه است.
- اجرای مدل ONNX داخل مرورگر با ONNX Runtime Web
- محاسبه امتیاز نهایی با میانگین وزن‌دار خطی؛ جدیدترین رکورد وزن بیشتری دارد.
- لاگ ساختاریافته و خروجی JSON برای عیب‌یابی

هشدار: راهنمای دیتاست فعلی، داده‌ها را مصنوعی و تصادفی معرفی می‌کند. معیارهای ارزیابی آن اعتبار عملیاتی ندارند.

## اجرای رابط برنامه

پیش‌نیاز: Node.js نسخه LTS

1. فایل `scripts/setup_windows.bat` را اجرا کن.
2. در پوشه پروژه دستور `npm run dev` را اجرا کن.
3. آدرس `http://127.0.0.1:5173` را باز کن.

## آموزش مدل

آموزش روی رایانه Windows خودت و با CPU انجام می‌شود؛ هنگام اجرای برنامه در مرورگر، Python یا فایل Excel لازم نیست.

1. Python 3.11 نسخه ۶۴ بیتی را نصب کن.
2. فایل `LocomotivDataSet.xlsx` را در مسیر `training/data/` قرار بده.
3. یک بار `scripts/setup_training_windows.bat` را اجرا کن.
4. برای تشخیص محیط و اجرای آموزش، `scripts/run_training_pipeline_windows.bat` را اجرا کن.

خروجی‌ها:
- مدل نهایی: `public/models/locomotive_model.onnx`
- مشخصات مدل: `public/models/metadata.json`
- گزارش معیارهای ارزیابی: `training/output/evaluation_report.json`
- پیش‌بینی‌های بخش آزمون: `training/output/evaluation_predictions.csv`
- گزارش آموزش: `logs/training.log`
- گزارش محیط Python: `logs/training_environment.log`

روش ارزیابی: ۸۰٪ داده برای fit اولیه و ۲۰٪ برای آزمون کنار گذاشته می‌شود؛ معیارهای MAE، RMSE و R² با یک baseline ساده مقایسه می‌شوند. سپس مدل نهایی از ابتدا با تمام ردیف‌های معتبر fit و به ONNX تبدیل می‌شود. جزئیات در `training/README.md` آمده است.

## سخت‌افزار پیشنهادی برای آموزش

- حداقل عملی پیشنهادی: CPU چهار هسته‌ای، RAM هشت گیگابایت و حدود دو گیگابایت فضای خالی SSD
- پیشنهاد راحت‌تر: RAM شانزده گیگابایت
- GPU لازم نیست؛ این نسخه از CPU استفاده می‌کند.

این اعداد برآورد منابع برای دیتاست فعلی‌اند، نه نتیجهٔ بنچمارک اندازه‌گیری‌شده.

## ارسال لاگ برای عیب‌یابی

- از پایین برنامه دکمه خروجی لاگ تشخیصی JSON را بزن و فایل را همین‌جا بفرست.
- خطاهای فنی در کنسول مرورگر با پیشوند `[LocomotiveAnalyzer]` ثبت می‌شوند.
- اگر خطا در آموزش رخ داد، `logs/training.log` و در صورت نیاز `logs/training_environment.log` را بفرست.
- لاگ برنامه مقادیر عددی ورودی را ذخیره نمی‌کند.
