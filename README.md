# LocomotiveAnalayzer

ابزار تحلیل قابلیت سیر لکوموتیو با معماری Frontend/Backend.

## اجرای برنامه در Windows

پیش‌نیازها: **Node.js LTS** و **Python 3.11 یا جدیدتر**.

1. فایل ZIP مدل را دستی در این مسیر قرار بده:

   `backend/models/model_bundle.zip`

2. فقط همین فایل را اجرا کن:

   `scripts/start_windows.bat`

اسکریپت به‌صورت خودکار وضعیت اجزای پروژه را بررسی می‌کند:
- محیط مجازی Python فقط در صورت نبودن ساخته می‌شود.
- وابستگی‌های Python فقط در صورت نصب نبودن یا تغییر فایل requirements نصب/به‌روزرسانی می‌شوند.
- وابستگی‌های Frontend فقط در صورت نبودن یا قدیمی بودن نصب می‌شوند.
- Backend با ZIP موجود اجرا می‌شود و آماده بودن مدل را بررسی می‌کند.
- در اجرای مجدد، Backend قبلی که توسط همین اسکریپت اجرا شده متوقف و با ZIP فعلی دوباره بارگذاری می‌شود.

سپس آدرس `http://127.0.0.1:5173` را در مرورگر باز کن. پنجره اجرا را تا پایان استفاده نبند.

**ساختار ZIP:** فایل ZIP باید شامل `locomotive_model.onnx` و `metadata.json` باشد. این فایل‌ها می‌توانند داخل زیرپوشه ZIP قرار گرفته باشند؛ نیازی به Extract دستی نیست.

## معماری

- Frontend: React + TypeScript + Vite
- Backend: Python + FastAPI
- اجرای مدل: ONNX Runtime در Backend؛ مرورگر مدل را دانلود یا اجرا نمی‌کند.
- فایل ZIP مدل روی دیسک میزبان نگهداری می‌شود و هنگام شروع Backend بارگذاری می‌شود.

## API

- `GET /api/health`
- `GET /api/model/status`
- `POST /api/model/upload`
- `POST /api/predict`

## استقرار سرور

در استقرار واقعی، Backend باید به‌عنوان سرویس دائمی اجرا شود و پوشه `backend/models/` روی دیسک پایدار سرور باقی بماند. نسخه فعلی برای اجرای محلی/شبکه توسعه است و API احراز هویت ندارد؛ پیش از انتشار عمومی باید احراز هویت، TLS، کنترل دسترسی آپلود و Rate Limit اضافه شوند.
