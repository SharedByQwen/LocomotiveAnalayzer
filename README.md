# LocomotiveAnalayzer

ابزار تحلیل قابلیت سیر لکوموتیو برای Windows با معماری Frontend/Backend.

## معماری فعلی

- فرانت‌اند: React + TypeScript + Vite
- بک‌اند: Python + FastAPI
- استنتاج مدل: ONNX Runtime در بک‌اند؛ مرورگر مدل ONNX را دانلود یا اجرا نمی‌کند.
- مدل و ZIP آن روی دیسک میزبان در `backend/models/` نگه‌داری می‌شوند.
- ارتباط فرانت‌اند با بک‌اند فقط از طریق API انجام می‌شود.
- تاریخ فقط برای مرتب‌سازی و شماره لکوموتیو فقط شناسه است؛ مدل چهار ویژگی عددی را دریافت می‌کند.

## راه‌اندازی Windows

پیش‌نیازها: Node.js نسخه LTS و Python 3.11 یا جدیدتر.

1. یک بار `scripts/setup_windows.bat` را اجرا کن تا وابستگی‌های فرانت‌اند نصب شوند.
2. یک بار `scripts/setup_backend_windows.bat` را اجرا کن تا محیط Python و API نصب شوند.
3. فایل ZIP خروجی Colab را در مسیر زیر کپی کن (Extract نکن):
   `backend/models/model_bundle.zip`
4. `scripts/run_app_windows.bat` را اجرا کن.
5. برنامه در `http://127.0.0.1:5173` در دسترس است.

همچنین می‌توانی از داخل خود برنامه، در بخش «وضعیت مدل»، ZIP را انتخاب و نصب کنی. بک‌اند ZIP را می‌خواند، فایل ONNX و metadata را اعتبارسنجی می‌کند و مدل را روی سرور بارگذاری می‌کند. ZIP اصلی نیز برای بارگذاری خودکار در اجرای بعدی نگه داشته می‌شود.

## ساختار ZIP مدل

ZIP خروجی Colab باید این دو فایل را داشته باشد؛ قرارگرفتن آن‌ها در زیرپوشه‌های ZIP هم مشکلی ندارد:
- `locomotive_model.onnx`
- `metadata.json`

نام فایل ZIP مهم نیست. نام دو فایل داخل ZIP باید همین باشد.

## API

- `GET /api/health`
- `GET /api/model/status`
- `POST /api/model/upload` برای نصب ZIP
- `POST /api/predict` برای پیش‌بینی دسته‌ای

در حالت توسعه، Vite مسیر `/api` را به Backend روی `127.0.0.1:8000` هدایت می‌کند.

## آموزش مدل

آموزش فعلاً در Google Colab انجام می‌شود. اسکریپت آموزش و جزئیات ورودی‌ها در `training/train_model.py` و `training/README.md` قرار دارند. پس از دانلود ZIP خروجی Colab، آن را مطابق مراحل بالا به Backend تحویل بده.

## تست فرانت‌اند

```bash
npm test
npm run build
```

## استقرار روی سرور

در استقرار واقعی، API باید به‌عنوان سرویس دائمی روی میزبان اجرا شود و پوشه `backend/models/` روی دیسک پایدار سرور قرار بگیرد. وب‌سرور یا Reverse Proxy باید درخواست‌های `/api` را به Uvicorn هدایت کند و فایل‌های build فرانت‌اند را سرو کند.

**مهم:** نسخه فعلی برای اجرای محلی/شبکه توسعه تنظیم شده است و API احراز هویت ندارد. قبل از انتشار روی اینترنت عمومی باید احراز هویت، TLS، محدودیت دسترسی آپلود و Rate Limit اضافه شوند.

## لاگ و عیب‌یابی

- لاگ‌های فرانت‌اند با پیشوند `[LocomotiveAnalyzer]` در کنسول مرورگر ثبت می‌شوند.
- لاگ‌های Uvicorn و خطاهای بک‌اند در پنجره Backend نمایش داده می‌شوند.
- خروجی JSON لاگ فرانت‌اند از پایین برنامه قابل دریافت است.
