# LocomotiveAnalayzer

ابزار تحلیل قابلیت سیر لکوموتیو با معماری Frontend/Backend.

## معماری

- فرانت‌اند: React + TypeScript + Vite
- بک‌اند: Python + FastAPI
- اجرای مدل: ONNX Runtime در Backend؛ مرورگر مدل را دانلود یا اجرا نمی‌کند.
- ارتباط فرانت‌اند و بک‌اند از طریق API انجام می‌شود.
- فایل ZIP مدل روی دیسک میزبان نگهداری می‌شود و در شروع Backend بارگذاری می‌شود.

## اجرای یک‌مرحله‌ای در Windows

پیش‌نیازها: **Node.js LTS** و **Python 3.11 یا جدیدتر**.

فقط همین فایل را اجرا کن:

`scripts/start_windows.bat`

مراحل به‌صورت خودکار:
1. پنجره انتخاب فایل باز می‌شود؛ ZIP خروجی Google Colab را انتخاب کن.
2. ZIP بدون نیاز به Extract در `backend/models/model_bundle.zip` ذخیره می‌شود.
3. محیط مجازی Python ساخته و وابستگی‌های Backend نصب می‌شوند.
4. وابستگی‌های Frontend نصب می‌شوند.
5. Backend اجرا می‌شود و وضعیت بارگذاری مدل بررسی می‌شود.
6. Frontend اجرا می‌شود.

سپس آدرس `http://127.0.0.1:5173` را باز کن. پنجره اجرا را تا پایان استفاده نبند.

در اجراهای بعدی نیز همین فایل را اجرا کن و ZIP جدید را انتخاب کن؛ محیط‌های نصب‌شده مجدداً ساخته نمی‌شوند و فقط در صورت نیاز وابستگی‌ها به‌روزرسانی می‌شوند.

## فرمت ZIP مدل

ZIP خروجی Colab باید حاوی این دو فایل باشد:
- `locomotive_model.onnx`
- `metadata.json`

این دو فایل می‌توانند داخل زیرپوشه ZIP هم باشند. نام خود ZIP مهم نیست. ZIP باز و بررسی می‌شود، اما کاربر نیازی به Extract دستی ندارد.

## API

- `GET /api/health`
- `GET /api/model/status`
- `POST /api/model/upload` برای نصب ZIP از رابط
- `POST /api/predict` برای پیش‌بینی

## استقرار سرور

در استقرار واقعی، Backend باید به‌عنوان سرویس دائمی اجرا شود و پوشه `backend/models/` روی دیسک پایدار سرور باقی بماند. وب‌سرور یا Reverse Proxy باید درخواست‌های `/api` را به Uvicorn هدایت کند و فایل‌های build فرانت‌اند را سرو کند.

**امنیت:** نسخه فعلی برای اجرای محلی/شبکه توسعه است و API احراز هویت ندارد. پیش از انتشار عمومی باید احراز هویت، TLS، کنترل دسترسی آپلود و Rate Limit اضافه شوند.
